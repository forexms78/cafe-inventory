시안 C — 밀도 재편

디저트39 신사역점 · 품목 128 · 카테고리 7 · 위치 3곳 · 모바일 PWA 중심(390px)

핵심 변경 3줄

  1. 1행을 상태점 · 품목명 · 3곳 합계 3요소로 압축 — 5열 표와 가로 스크롤을 제거하고 한 화면 표시 품목을 약 2배로.
  2. 2모든 조작은 행 탭 → 바텀시트로 이동 — 위치별 스테퍼 3개 · 유통기한 · 구매링크 · 최근 변경 2건을 한 곳에.
  3. 3128개 탐색 3중 장치 — 상단 검색 + 정렬 토글(기본·부족·이름) + 스티키 카테고리 헤더와 우측 빠른 점프 인덱스.

1 · 목록 — 기본순

  • 행 = 상태점 · 품목명 · 합계. 부족/주의는 배경 틴트 + 숫자색 + "최소" 캡션으로 이중 구분.
  • 상태점: 부족=채움+링, 주의=채움, 정상=테두리만 — 색약 사용자도 형태로 구분.
  • 우측 인덱스 레일로 카테고리 즉시 점프. 행 높이 54px(터치 44px+ 충족).

2 · 스크롤 중 — 스티키 헤더 + 점프 인덱스

  • 검색·정렬 바는 상단 고정, 현재 카테고리 헤더가 그 아래 붙어 위치를 항상 알림.
  • 인덱스 스크럽 시 카테고리 라벨 버블 표시(iOS 연락처 방식). 히트 영역 44px 확보.
  • 128개 품목도 검색 없이 3탭 안에 도달.

3 · 부족순 — 발주 동선

  • 부족 → 주의 → 정상 순. 카테고리는 인라인 칩으로 대체(그룹 해제 상태).
  • 상단 요약 칩(부족 6 · 주의 9)을 탭해도 이 화면으로 진입 — 아침 발주 체크가 10초.
  • 정렬 토글은 고정 폭 세그먼트 — 전환 시 레이아웃 시프트 없음.
바닐라시럽 매장 1 → 2

4 · 바텀시트 — 조작·정보 집약

  • 위치별 스테퍼 3개(버튼 44px). 매장 +가 눌린 상태 — 길게 누르면 연속 증감, 즉시 토스트 + 실행취소.
  • 숫자 탭 = 직접 입력. 사무실 0이라 − 비활성(자리 유지, 흐림 처리 — 시프트 없음).
  • 유통기한·구매링크는 데이터 있는 품목만 노출. 최근 변경 2건으로 "누가 언제" 즉시 확인.

데스크톱 — 시트가 우측 고정 패널로 (50% 축소)

  • 3열: 카테고리 내비(부족 배지) · 품목 목록 · 상세 패널. 행 클릭 = 패널 교체, 오버레이 없음.
  • 같은 행 컴포넌트 재사용 — 모바일과 정보 구조 동일, 배치만 재편.

공통 인터랙션 규칙

터치 타깃 44px+ — 행 54px, 스테퍼·세그먼트 44px. 요약 칩·인덱스는 시각 요소보다 큰 히트 슬롭으로 44px 확보.

레이아웃 시프트 금지 — 정렬 토글 고정 폭, 행 높이 고정, "최소" 캡션·비활성 버튼은 자리 선확보 후 표시/흐림 처리.

기존 동작 유지 — 30초 자동 갱신, 변경 토스트 + 실행취소, 로그 디바운스 병합, min_qty 문자열("2"·"3개"·"절반") 그대로 표기.

한국어 조판 — word-break: keep-all, 숫자는 tabular-nums. 시트 내 조건부 행(유통기한·구매링크)은 품목 데이터 유무로만 결정.
